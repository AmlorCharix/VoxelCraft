# VoxelCraft

A small playable voxel sandbox made with Python, Pygame, NumPy and ModernGL.

## Install
```powershell
py -m pip install pygame numpy moderngl
```

## Run
```powershell
py main.py
```

## Controls
- WASD: move
- Mouse: look around
- Space: jump
- F: toggle flight
- Shift: descend while flying
- Left click: break block
- Right click: place selected block
- 1-8 / mouse wheel: select hotbar block
- E: inventory panel
- F3: debug overlay
- F5 / Ctrl+S: save
- F9 / Ctrl+L: load
- Esc: release mouse; Enter: capture mouse again

World saves are written to `saves/world.json`.
